# NuTak

Interview practice with a little character. English / Русский.

## Current state

A self-contained static frontend in `index.html`. Open it in a browser to inspect the bilingual page and scripted introduction flow. No build or dependencies are required.

**This is a preview, not a functioning paid AI service.** It does not call an AI provider, process payments, save interviews, assess answers, or send email. Its notices make these limits visible.

- `PROJECT_BRIEF.md`: decisions, 15 provisional company/interviewer assignments, pricing and outstanding work.
- `research/company-interview-research.md`: official-source research with scope and verification gaps.

## Privacy and secrets

Do not add API keys, resumes, interview transcripts, emails or payment records to this public repository. Live data will require private backend storage and server-side payment verification.
